# AI-Powered Flashcard and Vocabulary Learning Application

An interactive vocabulary learning web application designed to help college students improve their English vocabulary through flashcards, quizzes, contextual examples, sentence practice, and revision tracking.

## About the Project

Learning a new word involves more than understanding its definition. Learners also need opportunities to recall words, understand their contextual usage, and practise using them in sentences.

The AI-Powered Flashcard and Vocabulary Learning Application aims to make vocabulary learning more structured and engaging by bringing word discovery, active recall, practice, and revision together in one interface.

- Provide an organized vocabulary library with search and filtering.
- Support active recall through interactive flashcards.
- Reinforce vocabulary understanding through quizzes.
- Encourage contextual learning through sentence practice.
- Help learners identify and revise difficult words.
- Track learning activity and progress.
- Explore AI-assisted vocabulary learning features.

## Key Features

- **Dashboard:** Access learning activities and vocabulary summaries.
- **Vocabulary Library:** Browse, search, and filter vocabulary words.
- **Word Details:** Explore definitions, parts of speech, and contextual examples.
- **Flashcards:** Reveal answers and mark words as known or needing revision.
- **Vocabulary Quiz:** Practise vocabulary with multiple-choice questions and score feedback.
- **Sentence Practice:** Write sentences using target vocabulary words.
- **Progress and Revision:** Review saved words and monitor recorded learning activity.
- **Settings and Help:** Access application guidance and relevant settings.

## Learning Workflow

**Discover → Understand → Recall → Practise → Revise**

The application is designed around this learning cycle to encourage repeated practice and better contextual understanding.
